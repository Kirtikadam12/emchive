# Emchive

### Continuous Teaching Intelligence & Skill Growth

Emchive is an AI-powered professional development platform that transforms everyday teacher experiences into structured evidence of competency growth.

## Problem

Teacher development happens continuously through training, classroom practice, feedback and reflection. However, this evidence is often scattered across notebooks, messages and personal memory.

Emchive brings these experiences together and helps teachers understand:

- What they are improving
- Where they have skill gaps
- What evidence supports those insights
- What they should work on next

## Core Flow

Teacher Input
→ AI Analysis
→ Evidence
→ Competency Update
→ Skill Gap
→ Personalized Recommendation

## Key Features

- Voice, text, photo and link capture
- Evidence creation
- Competency tracking
- Growth timeline
- Skill-gap detection
- Personalized development recommendations
- Explainable recommendations
- Confidence indicators
- Insufficient-evidence detection
- Offline/local persistence

## Competencies

- Foundational Literacy
- Foundational Numeracy
- Lesson Planning
- Classroom Management
- Differentiated Instruction
- Assessment

## Hackathon

Problem Statement: **MISC02 — Continuous Talent Intelligence & Skill Growth**

## Prototype

This repository contains the hackathon MVP of Emchive.

The current prototype uses rule-based analysis for the demo and simulated photo analysis. The architecture can be extended with a production LLM/multimodal AI service.

## Demo Flow

1. Capture a teaching experience
2. Analyze the experience
3. Create evidence
4. Update competency growth
5. Identify a skill gap
6. Generate a recommended next action
7. View the evidence behind the recommendation
8. Review the updated timeline and growth profile
